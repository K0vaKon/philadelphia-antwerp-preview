# Сайт церкви «Филадельфия»

Все актуальные файлы сайта находятся в этой папке. Для просмотра откройте
`index.html`; основные страницы сайта — `about.html`, `leaders.html`, `gallery.html`
и `admin.html`.

CSS-файлы, JavaScript и логотип также лежат рядом с HTML-страницами, поэтому
пути ресурсов не требуют дополнительных папок.

- `backups/` — резервные копии данных сайта.
- `gallery-admin.html` — отдельная защищённая страница управления фотографиями галереи.
- `gallery.css` — сетка галереи и миниатюры в админке.
- События, лидеры и фото галереи сохраняются в браузере и резервируются через админку.
- `archive/old-documents-copies/` — старые копии CSS и JavaScript, не используемые сайтом.
- `archive/previous-git-project/` — предыдущая копия проекта с историей Git; не редактируйте её вместо файлов сайта в корне этой папки.
